# VAMPIRO: A QUEDA DO REI
RPG por turnos para o terminal, feito em PHP com Orientação a Objetos.

> O Rei exterminou seu clã.<br>
> Você é o último vampiro.<br>
> Derrote todos os guardas e acabe com o Rei!

# 📖 Sobre o jogo

Você controla o último vampiro de um clã massacrado. Para se vingar, precisa enfrentar uma sequência de inimigos em batalhas por turnos, ficando mais forte a cada vitória, até chegar ao confronto final contra o Rei.

# Progressão
Ao derrotar um inimigo (exceto o Rei), o vampiro sobe de nível.
Se a vida do vampiro chegar a zero, o jogo termina em derrota.
Se o Rei cair, você vence.

# 🛠️ Tecnologias
PHP
Programação Orientada a Objetos (herança, encapsulamento e polimorfismo)
